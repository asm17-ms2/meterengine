가이드에서 쓰는 말과 콘솔 화면에 보이는 문구, API의 필드 이름이나 값을 한 줄에 맞춰 두었습니다. 뜻은 짧게만 적었으니 자세한 동작은 마지막 열의 페이지를 보세요. 콘솔 표기 칸이 비어 있으면 화면에 따로 이름이 없는 것이고, API 값 칸이 비어 있으면 API에 대응하는 값이 없는 것입니다.

| 기존 데이터 | 기존 데이터 | 웹훅 `environment` 값 `legacy` | 테스트 환경과 실제 환경이 나뉘기 전의 자료를 보존하는 범위. 새로 가입한 조직의 업무 환경 목록에는 나오지 않습니다 | [업무 환경](/concepts/environments) |
