가이드에서 쓰는 말의 뜻과 영문 표기(API의 필드 이름, 값, 경로 이름), 콘솔 화면에 보이는 문구를 한 줄에 맞춰 두었습니다. 뜻은 짧게만 적었으니 자세한 동작은 마지막 열의 페이지를 참고하세요. 칸이 비어 있으면 대응하는 표기가 없는 것입니다.

## 서비스와 계정

| 기존 데이터 | 테스트 환경과 라이브 환경이 나뉘기 전의 자료를 보존하는 범위. 새로 가입한 조직의 업무 환경 목록에는 나오지 않습니다 | `legacy` | 기존 데이터 | [업무 환경](/concepts/environments) |
| 키 구분 | 기존 데이터에서 키를 발급할 때만 보이는 입력란. 데이터 격리를 뜻하지 않습니다 | `mode` | 키 구분 | [업무 환경](/concepts/environments) |
