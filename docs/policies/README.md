# 정책

RFC가 정한 방향 안에서 실제로 적용되는 값을 도메인별로 적는 폴더다.

- 값은 정책 파일이 정하고 코드가 적용한다. 둘이 다르면 둘 중 하나가 버그다.
- 정책은 도입사가 겪는 값이다. 구현 세부는 코드가, 요청과 응답의 모양은 `backend/openapi.yaml`이 정본이라 여기 적지 않는다. 기준은 `docs/contributing/governance.md` "가르는 기준".

## 쓰는 법

1. 도메인 파일이 없으면 `template.md`를 복사해 `<백엔드 패키지명>.md`로 만든다.
2. 주제마다 절 하나, 규칙 하나가 표 한 줄. 값과 코드 위치를 적는다.
   - 코드 위치는 그 값을 단언하는 테스트 이름을 우선한다. 없으면 그 PR에서 만든다.
   - 왜 그 값인지는 커밋 본문에 적는다. 값을 다시 볼 조건이 있으면 표 아래 "재검토 조건:" 한 줄.
   - 근거, 담당자, 상태, 버전 열은 두지 않는다.
3. 값을 바꿀 때는 코드와 같은 PR에서 고친다. 리뷰어는 코드 위치가 grep되는지 확인한다.
4. 바꾸면 외부 계약이나 쌓인 데이터가 같이 움직이는 것은 정책이 아니라 RFC다.
