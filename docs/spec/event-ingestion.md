# 이벤트 수신과 귀속

이벤트 수신 시 식별자 해소, 시각 필드, 불변성의 경계 조건. 요청/응답 스키마는 `docs/api/openapi.yaml`이 정본이다.

## 식별자 해소

| 항목 | 값 | 근거 / 변경 가능성 |
|---|---|---|
| 해소 시점 | 수신 시 이름(external_customer_id, code)을 UUID로 해소 | ADR-0007. late binding은 구독-charge 매칭으로 한정 |
| 저장 형태 | 원문 이름과 해소 UUID(customer_id, meter_id)를 병행 저장 | ADR-0007 |
| 미등록 이름 | 거절하지 않고 UUID를 NULL로 저장 | ADR-0007. Lago 동일 패턴 |
| 미해소 이벤트 취급 | 집계에서 제외, 건수로 노출(관리자 화면 MS2-46) | ADR-0007 |
| 재연결 | NULL에서 값으로 1회 채움만 허용. 값 변경, 값 삭제 불가 | ADR-0007. 컬럼 단위 권한 + 가드 트리거로 강제 |

## 시각 필드

| 항목 | 값 | 근거 / 변경 가능성 |
|---|---|---|
| 필드 구성 | occurred_at(발생) / received_at(수신), 둘 다 NOT NULL | ADR-0009 |
| 저장 타임존 | UTC 정규화 | ADR-0009 |
| 귀속과 표시 경계 | KST 자정 | ADR-0009. 해외 도입사 발생 시 경계만 확장 |
| 계산 기준 | occurred_at (집계, 기간 귀속, 가격 참조 모두) | ADR-0009 |
| received_at 발급 | 서버가 찍는다. 클라이언트 입력 불가 | ADR-0009 |

## 경계

- 형식이 틀린 요청(필수 필드 누락, occurred_at 없음)은 4xx 거절. 형식은 맞는데 이름이 안 풀리는 이벤트는 미해소로 보존한다 (ADR-0007)
- 저장된 이벤트는 수정되거나 삭제되지 않는다(append-only). 유일한 예외는 해소 컬럼 2개의 NULL 채움이다 (ADR-0008)
- 정정은 보상 이벤트로 한다(구현은 후속 슬라이스). S1 기간의 수동 정리는 운영 롤 절차로만 하고 기록을 남긴다 (ADR-0008)

## 관련

- ADR-0007 수신 시 식별자 해소, ADR-0008 raw 이벤트 불변성, ADR-0009 시각 필드 의미론
- 스키마: `docs/erd/erd.md` USAGE_EVENT (가드 트리거, received_at 트리거 포함), V1 마이그레이션
- 구현/테스트: 수집 API 구현 시(MS2-38) 링크를 채운다
