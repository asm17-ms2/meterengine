# 금액과 단가

금액과 단가의 자료형과 계산 정밀도. 단수 처리의 규칙 값(절사 등)은 이 문서에 복사하지 않는다. 정본은 Notion 정책 P-01이며 테스트가 항목 번호를 참조한다.

## 규칙

| 항목 | 값 | 근거 / 변경 가능성 |
|---|---|---|
| 금액 자료형 | KRW 원 단위 정수 BIGINT, 컬럼명에 단위 표기(amount_krw) | ADR-0010. 변경 시 전체 재적재 |
| 단가 표현 | (unit_price_krw BIGINT, unit_size BIGINT) 쌍 | ADR-0010. "1,000토큰당 4원" = (4, 1000) |
| per-unit | unit_size=1의 특수 케이스 | ADR-0010 |
| 중간 계산 정밀도 | 고정밀(BigDecimal/NUMERIC), 부동소수점 금지 | ADR-0010, P-01-c |
| precise_amount | 소수 12자리로 고정, 확정 금액과 병행 저장 | P-01-d. API 명세(MS2-27) 예시와 동일 |
| 단수 처리 횟수 | 정확히 1회, 정해진 지점에서만 | ADR-0010. 지점과 규칙 값은 P-01 |
| 규칙 격리 | 절사/반올림 선택은 한 곳(상수/설정)에 격리 | ADR-0010. S2에서 도입사별 설정 승격 가능 |
| 가격 정책 이력 | 변경은 INSERT(버전 row). 현재 단가 = 미터별 created_at 최신, 동률 시 id 내림차순 | ADR-0012 |

## 경계

- 단수 규칙의 선택값(절사/반올림, 적용 지점)은 P-01이 정본이다. 코드와 이 문서에 값을 복사하지 않고 테스트가 P-01 번호를 참조한다
- 다통화는 미지원. 도입 시 currency 컬럼 추가로 확장하며 자료형은 바뀌지 않는다 (ADR-0010)
- effective_from 시점 rating은 미도입. 현재 단가 선택 규칙만 유효하다 (ADR-0012)

## 관련

- ADR-0010 금액과 단가 표현, ADR-0012 가격 정책 버전 row
- Notion 정책 P-01 (KRW 단수 처리 임시 규칙, S1)
- 스키마: `docs/erd/erd.md` PRICE_POLICY, INVOICE_LINE_ITEM
- 구현/테스트: common Money/KRW와 pricing 요금 계산 구현 시(MS2-40) 링크를 채운다
