# document-rules.md

문서를 어디에 두고 무엇을 정본으로 삼을지 정하는 규칙이다. 이 파일이 그 규칙의 정본이며, 다른 문서는 여기를 가리키기만 한다.

## 분담

가르는 기준은 하나다. **코드를 고칠 때 같이 고쳐야 하면 레포, 논의해서 정하는 것이면 Notion.**

| 종류 | 정본 |
| --- | --- |
| 정책, 스프린트 범위(이번에 하기로 한 것과 안 하기로 한 것), 결정 기록 | [Notion MS2 팀 위키](https://app.notion.com/p/MS2-3af0899b32b881f199ede2a87ac32a30) |
| API 계약 | `backend/openapi.yaml` (컨트롤러와 DTO에서 자동 생성) |
| 브랜치와 PR 규칙 | `CONTRIBUTING.md` |
| 각 디렉터리의 실행법, 구조, 그 안에서 내린 판단 | 그 디렉터리의 `README.md` |
| 이 규칙 자체 | 이 파일 |

한 내용을 두 곳에 쓰지 않는다. 레포에서 정책을 언급해야 하면 Notion을 가리키고, Notion에서 계약이나 실행법을 언급해야 하면 레포 파일을 가리킨다.

## 아직 정하지 않은 것

- `docs/` 아래에 무엇을 둘지. 정책이 Notion으로, 코드 옆 문서가 각 디렉터리 README로 가면서 지금 이 폴더에는 이 파일뿐이다. 새 문서를 만들기 전에 어디에 둘지 먼저 합의한다. 임의로 `docs/` 하위에 폴더를 만들지 않는다
