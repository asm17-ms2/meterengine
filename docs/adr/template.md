# ADR-{NNN}: {어떤 선택인지 드러나는 짧은 제목}

## 배경

{당시 상황과 요구, 제약, 충돌하는 조건을 이해할 만큼 짧게 적는다. 관련 기록이 있으면 연결한다.}

<!-- 선택 항목. 실제 비교한 대안이 있으면 작성하고, 없으면 이 절을 지운다. -->
## 검토한 선택지

{실제 비교한 대안과 선택 이유, 리뷰에서 나온 유효한 반론을 적는다.}

## 결정과 이유

{무엇을 선택하고 왜 선택했는지 적는다. 상세 구현은 필요한 코드와 문서에 연결한다.}

## 결과

{실제 예상되는 영향과 감수할 제약을 적는다. 문단이나 불릿으로 작성할 수 있으며, 긍정적, 부정적, 중립적 영향으로 나눠 쓰는 것은 선택이다.}
