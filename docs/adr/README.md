# ADR (Architecture Decision Record)

주요 설계 결정을 기록한다. 결정 대상 예시: 수집 경로, 저장소 구성, 집계 방식, 기술 스택 (MS2-28).

## 규칙

- 파일명: `NNNN-제목.md` (예: `0001-저장소-선택.md`). 번호는 만든 순서대로 증가하고 재사용하지 않는다
- 형식은 `template.md`를 따른다: 상태 / 결정 / 근거 / 대안 / 전환 조건
- 상태는 PR 흐름과 묶인다: "제안" 상태로 PR을 올리고, 합의되면 "승인"으로 바꿔 머지한다. 머지 = 승인이다. "제안" 상태로 머지하지 않는다
- 기각된 제안도 버리지 않는다. 상태를 "기각"으로 바꾸고 기각 사유를 적어 머지한다. 같은 논의가 재발하는 것을 막는 기록이다
- 승인된 ADR은 고치지 않는다. 결정이 뒤집히면 새 ADR을 만들고 양방향으로 잇는다: 새 ADR에 "NNNN을 대체함", 기존 ADR의 상태에 "대체됨(-> 새 번호)"
- 슬라이스 진행 중 필요한 시점에 결정한다. 전 범위를 미리 결정하지 않는다
