# docs

팀의 결정과 규칙. 여기에는 rfcs/, policies/, contributing/만 둔다.

- `rfcs/`: 되돌리기 비싼 방향 결정. 쓰는 법은 rfcs/README.md
- `policies/`: 방향 안의 세부 규칙과 값. 도메인당 파일 하나, 코드 PR과 같은 PR로 바꾼다. 쓰는 법은 policies/README.md
- `contributing/`: 팀 규칙. 주제당 파일 하나. 입구는 CONTRIBUTING.md

회의록과 일정은 Miro에 있다. 무엇을 어디에 두고 어떻게 바꾸는지는 contributing/governance.md가 정본이다.
