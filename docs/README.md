# docs

팀의 결정과 규칙. 여기에는 rfcs/, policies/, contributing/만 둔다 (RFC-000, RFC-005).

- `rfcs/`: 방향을 정하는 결정과 그 이유. 머지된 뒤에는 고치지 않는다. 쓰는 법은 rfcs/README.md
- `policies/`: 방향 안의 세부 규칙과 값. 도메인당 파일 하나, 코드 PR과 같은 PR로 바꾼다. 쓰는 법은 policies/README.md
- `contributing/`: 팀 규칙의 본문. 주제당 파일 하나, 목차는 루트 CONTRIBUTING.md. 만들고 고치는 절차는 contributing/decisions.md

회의록과 일정은 Miro에, 문서 위치 규칙은 CONTRIBUTING.md "문서의 정본"과 contributing/decisions.md에 있다.
